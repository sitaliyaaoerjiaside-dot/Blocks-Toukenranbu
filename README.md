# Blocks ＆ Touken Ranbu Mod

An unofficial fan-made Minecraft mod based on *Touken Ranbu*, built for **Minecraft 1.20.1** with **Forge**.

## Features
- **Touken Danshi Entities**: Uchigatana, Tachi, Ootachi, Naginata, Wakizashi, Tantou, Yari, and more
- **Enemy Factions**: History Retrograde Army and Kebiishi with unique AI and models
- **New Dimension**: Abandoned History — a wasteland dimension to explore
- **New Ores & Materials**: Coolant, Whetstone, and Wootz Steel with full tool and armor sets
- **Items & Charms**: Omamori, troop candy, dice, power of attorney, and other utility items
- **Patchouli Integration**: In-game encyclopedia for recipes and lore (EN / ZH_CN)

## Requirements
- Minecraft **1.20.1**
- Forge **47.4.0** or newer
- [GeckoLib](https://www.curseforge.com/minecraft/mc-mods/geckolib) (required for entity animations)
